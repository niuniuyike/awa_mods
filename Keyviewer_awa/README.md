# Keyviewer_awa

[中文](README.md) | [English](README_ENGLISH.md)

Minecraft **26.3** Fabric 客户端的按键显示 HUD（游戏内名称：Keyviewer Awa）。

在屏幕上实时显示 **W / A / S / D / 鼠标左键 / 鼠标右键 / 空格**，只有在你真正游玩的时候
（鼠标被游戏抓取、屏幕上没有光标）才显示；按 ESC、打开聊天、背包等任何界面时自动隐藏。

---

## 按键布局

```
        ┌───┐
        │ W │
┌───┐   ├───┤   ┌───┐
│ A │   │ S │   │ D │
├───┴───┴───┴───┴───┤        ← 左右键是横条，空隙正好在 S 正下方
│    L    │    R    │
├───────────────────┤
│      SPACE        │        ← 空格是细长条
└───────────────────┘
```

* 每个键都是带细边框的方块，键与键之间留有空隙
* 按键文字（W / A / S / D / L / R）会跟着「大小」一起缩放，**按下时文字不变色**（固定白色）
* 按下 / 松开是**渐入渐出**的过渡，不是硬切
* 按下时用「按下颜色」× 「按下时透明度」，松开时用「松开颜色」
* 左右键是横着的长方形，占满整行，中间的空隙对准 S 的中线，文字为 `L` / `R`

## 跟随鼠标移动

整块 HUD 会跟着鼠标移动：

* 鼠标**当前速度**决定 HUD 偏出去多少（速度越快偏得越多），匀速移动时 HUD 稳定停在偏出的位置
* 鼠标一停，速度归零，HUD 会**比较快地拉回原位**（往回收的速度比跟出去更快，有明显拉拽感）
* 鼠标朝反方向移动时，HUD 会**快速穿过原点**跑到另一侧
* 碰到屏幕边缘不会卡住：允许超出屏幕，但至少会保留一块按键可见，不会整块消失
* 改变窗口大小 / 分辨率时会自动重新取基准，不会把 HUD 顶飞
* 不想要这个效果的话，设置里把「位移跟随鼠标」关掉即可固定在设定位置

> 实现上速度取自 mixin 抓到的**原始鼠标增量**（`MouseHandler.accumulatedDX/DY`）。
> 不能用 `xpos()/ypos()`：那是绝对光标坐标，鼠标光标顶到窗口边缘就不动了，
> 会出现「鼠标一直在动、HUD 却回原点」的问题。

## 设置

游戏里输入命令：

```
/awakeyviewer
```

打开设置界面（带实时预览），可以调：

| 分类 | 项目 |
| --- | --- |
| 开关 | 移动键 WASD / 左右键 L·R / 空格键 / 位移跟随鼠标 |
| 颜色 | 边框颜色 / 按下颜色 / 松开颜色（RGB 滑块 + 直接改 16 进制代码） |
| 透明度 | 整体透明度、文字透明度、按下时透明度、松开时透明度、边框透明度 |
| 位置 | 位置 X、位置 Y（0~100% 屏幕） |
| 大小 | 0.5x ~ 3.0x（按键和文字一起缩放） |
| 灵敏度 | 0 ~ 2（平方曲线：低端更细腻，下限几乎不动；1.0 是默认手感） |
| 其他 | 重置 / 完成 |

颜色界面里可以直接编辑 16 进制颜色代码：

* `#` 固定在开头，删不掉也改不了
* 非法字符自动过滤，字母自动转大写，最多 6 位
* 只输入了一部分时，缺的位按 `0` 补全（例如 `#FF` = `#FF0000`），下方色块实时预览

设置保存在 `.minecraft/config/keyviewer_awa.json`，改完自动写入。

## 界面语言

界面文字跟随**游戏语言**自动切换，目前内置：

* 简体中文（`zh_cn`）
* English（`en_us`，其它语言找不到翻译时也会回落到它）

把游戏语言切到简体中文，`/awakeyviewer` 界面就是全中文的。

## 需要什么环境

| 依赖 | 版本 |
| --- | --- |
| Minecraft | 26.3 |
| Fabric Loader | 0.19.5 或更高 |
| Fabric API | 0.161.0+26.3 |
| Java | 25 |

## 安装

1. 装好 Fabric Loader（0.19.5+）
2. 把 `Keyviewer_awa-1.1.jar` 和 `fabric-api-0.161.0+26.3.jar` 一起放进 `.minecraft/mods/`
3. 启动游戏，进世界后左下角就能看到 HUD

## 自己重新构建

双击 `build.bat`（需要 JDK 25 在 PATH 里），产物在 `build\libs\`。
或者命令行：

```bash
gradlew build
```

## 说明

* 纯客户端 mod，装在服务器上不会被加载（`environment: client`）
* 26.3 用的是 Mojang 官方映射（Yarn 在 26.3 已停止），所以代码里是 `Minecraft` / `MouseHandler` 这类名字
* HUD 通过 Fabric API 的 `HudElementRegistry.addLast(...)` 注册
