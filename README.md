# awa_mods

[中文](README.md) | [English](README_ENGLISH.md)

Minecraft 轻量化 Fabric 模组合集

> **！！！本项目 95% 的代码编写由 AI 完成！！！**

## 模组列表

各模组已拆分为独立仓库，源码、Issue、Release 与使用说明请在对应仓库查看：

| 模组 | 作用 | 仓库 |
| --- | --- | --- |
| **Motd_awa** | 服务器 MOTD，支持定时刷新与随机轮换 | [niuniuyike/Motd_awa](https://github.com/niuniuyike/Motd_awa) |
| **Welcome_awa** | 玩家进入服务器时推送欢迎消息 | [niuniuyike/Welcome_awa](https://github.com/niuniuyike/Welcome_awa) |
| **Title_awa** | 玩家 AFK 后自动在名牌与 TAB 列表加上 `[AFK]` 前缀 | [niuniuyike/Title_awa](https://github.com/niuniuyike/Title_awa) |
| **QQbot_awa** | QQ 机器人与 Minecraft 服务器互通：状态查询、账号绑定、消息播报 | [niuniuyike/QQbot_awa](https://github.com/niuniuyike/QQbot_awa) |
| **Keyviewer_awa** | 客户端按键显示 HUD：实时显示 WASD / 左右键 / 空格，跟随鼠标移动 | [niuniuyike/Keyviewer_awa](https://github.com/niuniuyike/Keyviewer_awa) |
| **BetterList_awa**（待开发） | 更好的玩家列表 | — |

> 本项目95%代码由AI编写，awa_mods已分别新建仓库。

各独立仓库的 Release 均附带 Minecraft 26.1.2 / 26.2 / 26.3 的最新可用构建（Title_awa 自 26.2 起，Keyviewer_awa 为 26.3）。

历史版本与旧构建仍可在 [awa_mods Releases](https://github.com/niuniuyike/awa_mods/releases/) 下载。
