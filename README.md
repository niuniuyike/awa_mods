## 模组列表

- **Welcome_awa** — [wiki](https://github.com/niuniuyike/awa_mods/wiki/Welcome_awa) | [源码](./Welcome_awa)  
  为每个进入服务器的玩家推送欢迎消息

- **QQbot_awa** — [wiki](https://github.com/niuniuyike/awa_mods/wiki/QQbot_awa) | [源码](./QQbot_awa)  
  一款基于 Python 异步架构，实现 Minecraft 服务器实时状态监控、账号绑定及消息播报的智能机器人

- **Motd_awa** — [wiki](https://github.com/niuniuyike/awa_mods/wiki/Motd_awa) | [源码](./Motd_awa)  
  服务器 MOTD，支持定时刷新与随机轮换

- **Title_awa** — [源码](./Title_awa)  
  玩家 AFK 头衔：挂机后自动在名牌与 TAB 列表加上 `[AFK]` 前缀

- **Keyviewer_awa** — [源码](./Keyviewer_awa)  
  客户端按键显示 HUD：实时显示 WASD / 左右键 / 空格，跟随鼠标移动，`/awakeyviewer` 里可详细设置

- **BetterList_awa**（待开发）  
  更好的玩家列表
