# awa_mods

[中文](README.md) | [English](README_ENGLISH.md)

Lightweight Fabric mods for Minecraft

> **！！！95% of the code in this project is written by AI！！！**

## Mod list

Each mod now lives in its own repository — see the repo for source, issues, releases and usage:

| Mod | What it does | Repository |
| --- | --- | --- |
| **Motd_awa** | Server MOTD with scheduled refresh and random rotation | [niuniuyike/Motd_awa](https://github.com/niuniuyike/Motd_awa) |
| **Welcome_awa** | Sends a welcome message to every player joining the server | [niuniuyike/Welcome_awa](https://github.com/niuniuyike/Welcome_awa) |
| **Title_awa** | Adds an `[AFK]` prefix to the name tag and tab list when a player goes idle | [niuniuyike/Title_awa](https://github.com/niuniuyike/Title_awa) |
| **QQbot_awa** | QQ bot bridge for Minecraft servers: live status, account binding and broadcasts | [niuniuyike/QQbot_awa](https://github.com/niuniuyike/QQbot_awa) |
| **Keyviewer_awa** | Client-side key viewer HUD: WASD / mouse buttons / space bar, sways with mouse movement | [niuniuyike/Keyviewer_awa](https://github.com/niuniuyike/Keyviewer_awa) |
| **BetterList_awa** (planned) | Enhanced player list | — |

> 95% of this project's code is written by AI; each mod now has its own repository.

Each standalone repo's release includes the latest available builds for Minecraft 26.1.2 / 26.2 / 26.3 (Title_awa from 26.2, Keyviewer_awa for 26.3).

Older versions and builds remain available on [awa_mods Releases](https://github.com/niuniuyike/awa_mods/releases/).
